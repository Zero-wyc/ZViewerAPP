# iOS 1.8.5 / build 21 真机测试包

日期：2026-10-13。用户授权合并一起听后台播放及 B站 VLC 音频修复后构建 IPA；本轮不推送源码或发布 GitHub Release。

## 真机回归更正

用户确认本包加载卡顿、Jellyfin 点播放卡死，B站视频及一起听同样无法正常播放。**本包停止推荐。** 下文的测试和产物检查通过不代表原生运行正确。后续定位到 VLC 回调线程同步等待主线程、主线程等待 VLC 播放器锁的等待链；异步回调和非阻塞通知修复见 [维护文档](../ios-maintenance-architecture.md)，目标 build 22。

## 修复内容

- 一起听音频视图显式传递原生 `backgroundAudio` 属性，禁用隐藏 PiP，并在 VLC 媒体参数中关闭视频输出。进入后台时原生配置播放音频会话并放行音乐视图，避免依赖异步 Now Playing 信息。
- 空闲旧语音引擎退出时不再改写共用音频会话；真正释放自身引擎时恢复并激活播放会话。不因退后台主动恢复用户已暂停的曲目。
- 合并 B站分离音轨延迟挂载、成功去重及失败重试修复。修正 EAS prebuild 后再次安装依赖覆盖补丁的问题：重装后重新应用，在 Xcode 编译前强制验证。
- 轨道诊断排除“关闭音轨”选项，避免零真实音轨误报为一轨。Jellyfin 内置音频与一起听 B站直出音频路径保留。

## 真机复验

| 场景 | 预期行为 |
| --- | --- |
| 网易云播放中退至桌面、锁屏保持数分钟 | 当前曲目持续有声；控制中心暂停/恢复符合操作。 |
| 一起听 B站音频退至桌面、锁屏 | 持续有声，返回前台播放器与曲目保留。 |
| 主动暂停后退后台或锁屏 | 保持暂停，不擅自恢复。 |
| 服务端添加 B站视频后 iOS 一起看 | 图片与音频正常，诊断显示真实音轨。 |
| iOS 添加 B站视频后网页加入 | 两端有画面和声音，暂停与拖动同步。 |
| Jellyfin 影片、语音加入/退出、蓝牙与来电 | 保留既有声音路径，中断和恢复符合播放意图。 |

这些检查不能由 Windows 或离线包检验替代。JS 被系统暂停时仍无独立原生房间 Socket/切歌/观众审批管线，不能宣称后台同步与自动切歌完全闭环。未签名 IPA 需要用户自行签名后安装。
