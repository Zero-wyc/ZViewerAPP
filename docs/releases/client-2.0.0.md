# ZViewer-Client V2.0.0

发布日期：2026-10-15。Android / HarmonyOS：`2.0.0 / 200`。

## 🚀 新特性 / Features

- Android、HarmonyOS 可作为手机房主共享屏幕，支持画面与声音暂停、恢复、停止及最多 4 位观众。
- 系统声音、麦克风分别选择；房间语音使用麦克风时共享自动让出，避免重复占用。鸿蒙补齐后台持续共享。
- 分辨率提供本机、720P、1080P、2K、4K；Android 可请求 30/60/90 fps，鸿蒙提供 30/60 fps。界面显示实测采集帧率，实际性能取决于设备与画面。
- 一起看播放键旁新增下一部按钮，使用三角形加竖线图标，按完整片单顺序切换，沿用房主、房管及房间权限设置。

## 🐛 错误修复 / Bug Fixes

- 修复一起听全屏打开播放队列导致黑屏、音频停止，以及背景与全屏重复展开队列。
- 修复触屏平板上网易云、B站搜索入口被鼠标悬停逻辑隐藏；窄屏保留搜索按钮，宽屏常驻搜索框并提高背景不透明度。
- 修复中等宽度下搜索框遮挡来源导航；缩短播放器弹幕输入框，窄屏、全屏均保留下一部操作空间。
- 大屏聊天与片单吸附右侧，视频在剩余空间居中；房间语音面板避开顶部栏和安全区。
- 房间模式统一为“一起看、投屏、一起听”，同排显示；投屏使用独立图标，片单移除重复 B站账号入口。
- 下一部请求期间防止重复操作，失败保留当前影片并允许重试；末尾禁用，预览、切房及权限变化时阻止过期切换。

## ⚠️ 破坏性改动 / Breaking Changes

- 无新增服务端协议要求。本版按最终需求不新增自动连播开关。
- 本次仅发布 Android 和 HarmonyOS。iOS 维持原有 1.9.0 / build 26，本轮不构建、不重新上传 IPA。
- 鸿蒙继续不提供画中画；鸿蒙 90 fps 档位因系统录屏能力限制不可选，目标帧率不代表持续实际帧率。

## ⚡ 性能优化 / Performance Improvements

- Android 发送器取消固定 30 fps 限制，按实际尺寸与目标帧率调整码率预算；音频使用 10 ms 采集时钟。
- 麦克风共享与房间语音协调单次物理采集、轨道引用和硬件交接；停止后释放系统采集与持续任务。
- 工具栏仅测量正常布局子项，避免队列浮层引起反复布局和 React 无限更新。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步 Android/HarmonyOS 维护文档、README、CHANGELOG 及 2.0.0 验证记录；未新增运行时依赖。
- 155 项适配、4 项媒体回归通过；16 组触屏搜索、12 组下一部操作检查通过，每组下一部均覆盖普通和全屏布局。
- 鸿蒙屏幕共享由用户真机验收；Android 按约定使用虚拟机完成音画与后台持续测试。新搜索/下一部检查采用原生 WebView/ArkWeb、系统点击和隔离测试数据，生产账号及跨端媒体同步不由界面夹具代替。
- 双端安装包均由最终 2.0.0 源码重新构建并沿用既有发行签名，附 `SHA256SUMS.txt`；源码直接同步 main，使用 GitHub 自动源码归档。
