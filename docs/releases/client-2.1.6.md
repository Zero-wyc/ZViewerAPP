# ZViewer-Client V2.1.6

Android / HarmonyOS 同步更新为 **2.1.6 / 216**，改善长名称显示与选集布局。构建与双端模拟器验收范围见 [验证记录](https://github.com/Zero-wyc/ZViewerAPP/blob/main/docs/client-2.1.6-validation.md)。

## 🚀 新特性 / Features

- 浏览窗口上方增加“完整显示”滑动开关，默认打开；长剧名、影片名和分集名称自动换行，本机记住选择。标题与操作优先同排，宽度不足再换行。
- 选集增加明确的“列表 / 网格”选项：列表每集一行；网格按选集区域实际宽度自动增加或减少列数。选集布局独立保存，切换时保留已选集数。
- 覆盖 Kazumi、ani-subs、TVBox/CMS、B站分 P，以及 Emby/Jellyfin 季内分集浏览。

## 🐛 错误修复 / Bug Fixes

- 修复相似长剧名被省略后难以区分的问题，完整名称模式下不限制标题行数，连续英文和文件名也可断行。
- 已添加影片的下拉选集同时显示当前集与各选项完整名称；整部添加按钮与标题分别留出空间。
- 目录导航独立保持单行，各级名称等宽，超长用省略号；完整显示开关不改变目录高度。

## ⚠️ 破坏性改动 / Breaking Changes

- 无。播放协议、房间同步与原生媒体逻辑保持兼容。
- Android 最低 API 24，鸿蒙最低 SDK 6.1.0(23)。iOS 保持既有版本，本轮不构建或发布。

## ⚡ 性能优化 / Performance Improvements

- 名称与选集布局切换复用当前列表数据，无需重新搜索或获取分集。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步安卓、鸿蒙维护文档及本版验证记录；依赖版本不变。
- 206 项适配、4 项媒体和 6 项 vendor 检查通过；完成双端模拟器选集交互、168 组基础布局及自适应网格追加验证。768px 实测五列，展开的大屏面板可达十列。
- 提供重新构建的正式签名 APK、HAP 与构建时生成的 `SHA256SUMS.txt`。源码同步 main，使用 GitHub 自动生成的源码归档。
- 双端模拟器验证使用实际打包界面与隔离本地服务，第三方番剧结果为长名称夹具；验证范围不扩大为实体设备或真实源站可用性。
