# ZViewer-Client V1.8.6（本地候选，未发布）

Android/HarmonyOS 为 1.8.6 / 186；iOS 为 1.8.6 / build 25，未签名设备包。新增行为等待真机复验，详见 [验证记录](client-1.8.6-local-validation.md)。

## 🚀 新特性 / Features

- 安卓、鸿蒙主页新增“关于应用”，可查看安装版本、手动检查更新和发布记录。
- 应用启动自动检查正式客户端版本，发现更新后提示下载对应平台的 APK/HAP，通过系统浏览器获取安装包。

## 🐛 错误修复 / Bug Fixes

- iOS 同步观影采用服务器权威心跳，消除房主/服务器两套采样交替纠偏；加载、主动 seek 和旧媒体回调不会重复拉进度。
- iOS 音乐换曲复用原生视图并直接换源，后台系统控制不再延迟到前台；换曲间隙使用有限后台执行时间。
- iOS 音乐拖到末尾按队列模式切歌、重播或停止，避免 EOF seek 循环。
- 外部媒体 HEAD 探测失败不再误报为服务器连接失败。

## ⚠️ 破坏性改动 / Breaking Changes

- 无协议破坏性改动。新增自检通道兼容最新服务端；旧服务器不返回自检时仍通过心跳同步。
- iOS 仍需自行签名安装；鸿蒙 HAP 沿用设备授权/Profile 安装要求。

## ⚡ 性能优化 / Performance Improvements

- 纯进度心跳不重复解析/重建播放输入；音乐复用同一原生视图，减少后台换源时的 UI 提交依赖。
- 更新检查有超时、限流及离线反馈，同一启动周期避免重复自动提示。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步更新 README、CHANGELOG 和三端维护文档；依赖版本保持现有范围。
- 本地服务端源码下载覆盖到最新 `89eafa5`，没有修改 NAS 容器或提交服务端补丁。
