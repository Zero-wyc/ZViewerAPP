# ZViewer-Client V1.7.4

2026-10-12。本地 Android / HarmonyOS **1.7.4 / 174**，对齐服务端 v4.5.1 固定提交 `c8fa5bad0c6efcffbc0dc3bfe4c199f8a9b8d8f6`。未发布 GitHub，iOS 不涉及。按用户要求排除公告。

## 🚀 新特性 / Features

- 共享 Kazumi/ani-subs 搜索、来源切换、海报和集中选集，保留关键词/放大及失败项重试。
- Emby/Jellyfin 搜索、整剧/整季单卡、卡内切集与多版本选择。
- 按 root/房间创建者权限清空整个片单，B 站搜索结果内分 P 选择。

## 🐛 错误修复 / Bug Fixes

- 修复媒体库无 tag 海报、集号/总集数元数据及转码 HLS 相对分片。
- 修复切源/切集/切版本/切房的旧响应覆盖、清空后残留播放和恢复状态。
- 修复窄屏操作栏、长面包屑及搜索框挤压；完善音量拖动取消与嵌套滚动锁。

## ⚠️ 破坏性改动 / Breaking Changes

无新增客户端破坏性协议。新搜索/清空/多版本能力需要新服务端；旧服务端失败明确反馈。既有编解码及原生能力限制保持。

## ⚡ 性能优化 / Performance Improvements

版本信息按需加载；失败集数重试只补未成功条目；旧图片 Blob、拖动监听和播放请求按生命周期释放。

## 📖 文档与依赖更新 / Documentation & Dependencies

同步双端维护文档、更新指南实施范围、README 和 CHANGELOG；依赖版本未升级。56 项适配、4 项媒体、102 组浏览器界面及双端实际 App/播放联调通过；[验证记录](../client-v1.7.4-alignment-451-validation-20261012.md)列出具体覆盖和用户设备待验收内容。
