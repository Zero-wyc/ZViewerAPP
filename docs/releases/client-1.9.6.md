# ZViewer-Client V1.9.6

本地发行说明草稿；尚未发布 GitHub Release。Android / HarmonyOS 构建号 196，iOS 沿用已有版本。

## 🚀 新特性 / Features

- 双端手机房主屏幕共享：开始、暂停画面与声音、恢复、停止，最多 4 位观众；继续使用原有房间信令和 WebRTC 观众。
- 系统声音与麦克风可独立共享，房间语音接管时自动让出共享麦克风，避免重复发送同一句话。
- 本机、720P、1080P、2K（1440P）、4K（2160P）画质档位。Android 目标 30/60/90 fps；鸿蒙系统录屏上限 60，提供 30/60，90 档显示不可用。界面展示采集实测帧率。

## 🐛 错误修复 / Bug Fixes

- 修复鸿蒙切换应用后共享停止，使用正确的录音/播放持续任务和匹配子模式，系统撤销后释放全部采集资源。
- 共享页使用应用原有图标、主题和背景；修复固定黑色验证面板与整体外观不一致。
- 大屏聊天/片单贴右、视频在剩余区域居中；语音面板在顶部栏下方展开。模式入口统一“一起看、投屏、一起听”，片单移除重复 B 站账号图标。
- 已知管理员禁言同时作用于共享麦克风；停止房间语音后不会绕过禁言。系统声音共享时禁用本地语音监听，Android 排除本应用播放声音。

## ⚠️ 破坏性改动 / Breaking Changes

- 无服务端协议变更。系统音频取决于系统及播放应用的录制策略，Android 需要 Android 10 及以上。
- 画质为目标上限，按原屏幕比例缩放且不放大源；实际帧率取决于采集、编码、屏幕刷新与网络。鸿蒙没有固定 30 fps 限制，当前设备 720P/60 动态实测约 39.7 fps，不能承诺全设备稳定 60。

## ⚡ 性能优化 / Performance Improvements

- Android 采集与编码使用所选帧率，按实际分辨率调整码率预算；原生音频采用单调 10 ms 时钟，房间语音与共享之间串行交接麦克风。
- 鸿蒙采集实测通过 VideoFrame 私有克隆计数，不读像素、不额外编码；停止时清理 reader、克隆、混音和持续任务。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步 Android / HarmonyOS 维护手册、交付计划与设备/模拟器验证报告；Android WebRTC 固定为 `144.7559.15`。
- 鸿蒙 v4/v5 已由用户真机确认，Android 本轮按用户要求用虚拟机验证。公网复杂 NAT/TURN 和长期热量/耗电不在已通过证据内，完整边界见验证报告。
- 交付签名 APK、HAP 与每包构建后一次生成的 SHA256SUMS.txt；iOS 本轮不构建，不另打包源码压缩包。
