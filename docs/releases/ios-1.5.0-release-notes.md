## 🚀 新特性 / Features

- iOS 客户端版本与 Android/鸿蒙对齐为 **1.5.0（build 15）**，提供内置 JS 的 iPhone/iPad ARM64 未签名 Release IPA。
- 对齐双端的全局背景与深浅主题、连接页/房间、集中选集、音乐发现和展开播放器；横屏显示右侧菜单，竖屏显示视频下方菜单。
- 网易云歌单支持全部播放（替换队列并从首曲播放）及全部加入播放列表；私人漫游持续补充推荐，支持模式/场景和喜欢/不喜欢。
- 增加每日推荐日期选择（默认当天，历史日期由服务端返回）、满宽音乐横幅、左右滑动与首尾循环。
- 在线弹幕搜索采用可滚动弹窗、来源下拉与每行两个集名；保留 VLC、本机 B站、语音、系统媒体控件、歌词和字幕路径。

## 🐛 错误修复 / Bug Fixes

- 修复开屏布局增长导致只剩外观按钮、房间视频/音乐区域缺失，以及横竖切换后展开菜单越界。
- 修复横幅复用专辑方图裁切、两侧留白及连续手势位移误判；竖向滑动仍可滚动页面，手动切换避开自动轮播。
- 完善会话恢复超时和旧请求隔离、B站登录入口说明、背景文字对比度及图片代理请求属性保留。
- 歌单分页预加载失败保留旧队列；批量写入显示进度、取消与实际完成数量，弹幕导入失败保留选择供重试。

## ⚠️ 破坏性改动 / Breaking Changes

- **IPA 未签名，需要自行签名后安装**，不是 App Store/TestFlight 包。支持范围与最低系统版本见交付记录；iPad Split View 继续关闭。
- 用户已确认 iOS 真机 **UI 检测通过**。本次不将此扩大为音视频、语音或后台完整功能的真机验收：JS 完全暂停时的独立房间 Socket 心跳/切歌/审批仍未闭环，系统完整歌词页与部分双端权限行为有差异。
- 服务端目标 v4.2.1；媒体解码、真实账号/来源、蓝牙/来电和长期后台播放的验证边界见源码中的交付记录。

## ⚡ 性能优化 / Performance Improvements

- 限制歌词/解析缓存与漫游候选内存，合并相同请求；切换账号、房间、模式和媒体时丢弃过期结果。
- 会话恢复不再无限阻塞界面；歌单按页预加载、逐首等待服务端确认；大列表在独立区域内滚动。
