# iOS 目录片源弹窗预览验证 — 2026-10-13

本次对齐用户提供的服务端截图及当前 `ServerFilesBrowser.tsx`、`MountBrowserBase.tsx`。范围为 iOS 的 OpenList、FTP、WebDAV、服务器文件；添加影片使用简洁入口，浏览打开独立弹窗。iOS 保持 VLC 播放路径。

## 改动

- `DirectoryPicker.tsx`：空间/挂载选择、手动路径、浏览、可展开弹窗、上级/当前目录、单选/多选/全选文件，以及固定取消/添加底栏。
- `directorySources.ts`：四种片源的 roots/browse/resolve、根目录边界和路径身份、取消、批量部分失败重试。
- `SourcePicker.tsx`：移除内嵌目录列表，使用统一目录组件；添加后保留面板以便继续操作。
- `directorySources.test.mjs`：新增 7 项协议、路径、部分失败重试与 RN 取消测试。
