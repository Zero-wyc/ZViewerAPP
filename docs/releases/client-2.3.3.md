# ZViewer-Client V2.3.3

Android / HarmonyOS 更新为 **2.3.3（233）**，本版重点更新一起听的触屏界面、歌词和播放队列。

## 🚀 新特性 / Features

- 封面与歌词共用进度条和五键播放控制；点击封面或横滑切换歌词，迷你播放条支持点击或上滑展开。
- 歌名独占整行并在超长时滚动，歌手行集中提供喜欢、歌词和评论图标；更多操作统一到右上角。
- 播放队列改为底部面板，支持拖动排序、键盘排序、左滑删除及清空确认；歌曲行单击播放，菜单提供下一首、加入队列、收藏到歌单和专辑入口。
- 小屏横屏在展开歌词时显示封面缩略图，收起歌词时显示大封面；播放信息、进度和五键整体居中，适配挖孔与手势条。
- 罗马音、翻译图标与音质统一放到歌词框右下角，竖屏歌词向上填满原按钮行的空间；设置分为外观和默认折叠的高级选项。

## 🐛 错误修复 / Bug Fixes

- 修复网易云喜欢状态在多个入口之间不一致、快速点击与迟到查询互相覆盖，以及账号切换后旧响应干扰新状态的问题。
- 修复滑动切歌后合成点击误触；进度拖动取消或换曲后不提交过期跳转。
- 修复小屏横屏播放控制拥挤、封面不可见和歌词页脚色带；歌曲信息、进度和五键使用固定间距，避免矮屏溢出。
- 罗马音和翻译按钮随歌词面板切换深浅色，消除深色背景下图标偏暗；页脚独立占位，不遮挡歌词。
- 歌词上下边缘增加渐隐，旋转、字体和页脚尺寸变化后继续校正当前行；空歌曲时也能从顶栏打开设置。
- 保留观众的控制申请、房主审批和同步回执，队列清空前明确显示数量并确认，避免误操作。

## ⚠️ 破坏性改动 / Breaking Changes

- 系统要求与发布签名不变：Android 7.0 / API 24，HarmonyOS 6.1 / API 23。
- 一起听歌曲行改为单击播放；本机音量和设置从右上角更多菜单进入，原底部独立工具栏移除。
- 常用播放模式按“列表循环 → 单曲循环 → 随机播放”切换；“按顺序播放（播完停止 / B站推荐连播）”移入更多菜单，兼容既有房间状态。

## ⚡ 性能优化 / Performance Improvements

- 喜欢状态查询去重并共享缓存，多个界面复用同一份状态；乐观更新、串行点击与迟到响应隔离减少重复请求。
- 精简播放器与队列重复入口和弹窗，减少重复挂载；菜单动画遵循系统减少动态效果偏好。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 更新 Android / HarmonyOS 维护文档、一起听最终布局记录、README 和 CHANGELOG；依赖版本未变。
- 已通过 161 项维护回归、8 项工具栏/音质回归、TypeScript/Vite 与双端签名构建。最终歌词页完成 393×852、320×568、852×393、720×320 的布局和实际点击检查。
- 最后一轮截图采集失败；浏览器和构建结果不替代 Android WebView / HarmonyOS ArkWeb 真机触摸、听感、后台和多人同步验收。
- 提供签名 APK、HAP 及构建时生成的 SHA256SUMS.txt；源码更新至 main，使用 GitHub 自动生成的源码归档。iOS / iPadOS 保持 2.1.10 / build 31。
