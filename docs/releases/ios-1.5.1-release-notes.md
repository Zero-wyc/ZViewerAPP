# ZViewer iOS 1.5.1

**版本说明：本次 Release 标签和 iOS 源码版本为 1.5.1；未重新触发 Expo/EAS 构建。安装包复用已完成修复并校验的 1.5.0 / build 16 未签名 IPA，安装后显示的内部版本仍为 1.5.0（16）。附件保留真实版本文件名，请勿将其视为重新编译的 1.5.1 安装包。**

本次为独立 iOS 发布；包含本轮源码修复、维护文档、原始 build 16 验证证据和源码 ZIP。

## 🚀 新特性 / Features

- 播放设置整合“播放 / 字幕 / 弹幕”页签；字幕管理、导入及同步设置可从视频齿轮进入，全屏同样可用。
- 音轨、字幕和倍速的当前选中项显示主题色高亮与勾号；轨道状态随本机选择和原生回调刷新。

## 🐛 错误修复 / Bug Fixes

- 修复一起听每次房主心跳都发送“已同步”回执的问题；每个曲目/连接在媒体准备完成后仅回执一次，切歌和重连允许新回执。
- 修复 B 站分享文本包含标题时的 `Invalid URL`：规范提取链接，保留分 P/CID，覆盖片单恢复、添加和解析路径。
- 修复缺省轨道隐式选中 0 号及切换时旧轨道叠加的风险；原生字幕与同步文本字幕互斥，减少 ASS 特效旁额外纯文本的重复渲染。
- 换片清空旧字幕地址、延迟和轨道选择，避免设置面板显示上一部影片的状态。

## ⚠️ 破坏性改动 / Breaking Changes

- 无新增接口破坏性改动。原独立“字幕管理”入口移至“播放设置 → 字幕”。
- **IPA 未签名，需要自行签名安装。** 本次复用 1.5.0 / build 16 二进制，源码版本提升至 1.5.1；没有新的 Expo/EAS build。
- 原生音轨/字幕高亮和 ASS 最终视觉效果仍需真机复验；桌面 VLC、Web 检查与包校验不能替代 iOS 音视频、语音和后台完整验收。

## ⚡ 性能优化 / Performance Improvements

- 同步回执按服务器、用户、房间、Socket 连接和曲目隔离、去重，减少重复网络事件及房主提示堆积。
- 相同原生轨道列表不重复触发 JS `sourceLoad`，减少设置面板无效刷新。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 补全 iOS 维护架构，记录工程模块、轨道补丁、字幕互斥、同步回执、构建流程和真机复验步骤。
- iOS 源码版本统一为 1.5.1，依赖版本保持现有构建配置；本次未重新构建安装包。
- 复用 build 16 已通过的 **74/74 单测、18/18 Web 界面检查、lint、TypeScript 及 iOS/Web 导出**证据。指定《败犬女主太多了！》S01E02 MKV 完成两字幕切换/关闭/恢复和 55/120/700/1300 秒本地 seek 辅助检查。
- IPA 已校验为 ARM64 iOS 设备包，支持 iPhone/iPad、最低 iOS 16.4，包含内置 JS、VLC、B 站/语音/系统媒体原生模块及许可证。
- 复用 IPA 的 SHA-256：`1220bdd48cf9308eb98d2b71b32e95c365c8d3cfe312bdbb25ab92b0e3e28ac7`。其余附件摘要见 `SHA256SUMS-ios-1.5.1.txt`。
