# ZViewer-Client V2.1.4

Android / HarmonyOS 2.1.4 / 214，本地交付，尚未发布 Release。最终 HAP 的鸿蒙投屏横竖屏修复已于 2026-10-20 获用户真机验收通过；真机证据和验收范围见 [验证记录](../client-2.1.4-validation.md)。

## 🚀 新特性 / Features

- 无新增独立功能。

## 🐛 错误修复 / Bug Fixes

- 修正鸿蒙投屏旋转仍固定在初始画布的问题：在同一次原生采集中按物理屏幕比例去掉系统补边，持续输出方向正确的横屏/竖屏帧，保持原连接与音频。
- 实际送达帧提供分辨率和帧率统计，生成轨道配置帧率不可用时不显示为实测值。
- 保留 Android 2.1.3 的原生旋转修复。

## ⚠️ 破坏性改动 / Breaking Changes

- 沿用媒体库 HLS 服务端 v4.6.4 最低契约；鸿蒙运行时检查所需视频帧处理接口，最低 SDK 保持 6.1.0(23)。

## ⚡ 性能优化 / Performance Improvements

- 逐帧转交可见区域与显示尺寸，释放全部帧资源；不读像素、不使用 Canvas 定时绘制，也不额外申请采集或创建另一套编码器。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步两端维护文档，补充用户真机失败原因和修正后的电脑接收端证据；188 项适配、4 项媒体测试通过。
- iOS 不修改、不构建。
