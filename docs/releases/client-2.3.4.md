# ZViewer-Client V2.3.4

Android / HarmonyOS 更新为 **2.3.4（234）**，重点修复一起看 B站反复中断后的恢复和播放同步。用户已确认本轮测试通过。

## 🚀 新特性 / Features

- B站原生播放持续缓冲时可自动重新解析地址，无需等待播放器报告错误；恢复设有超时和取消保护，保留手动重新加载入口。
- 手动选择的画质在恢复时保持所选档位；自动画质模式按需回退，并在正常播放后重新获得恢复额度。

## 🐛 错误修复 / Bug Fixes

- 修复多次中断后恢复次数持续累计，最终停止自动恢复的问题。
- 修复恢复期间点击“暂停”被临时媒体状态误判为“播放”的问题；暂停立即同步，重新加载完成后不会自行续播。
- 修复换源时零进度或临时暂停影响房间同步的问题；手动同步和新观众加入保留有效进度，恢复后同步最新源与画质。
- 修复观众复用过期音视频地址，以及切换房间、账号、影片或画质后旧任务干扰当前播放的问题。
- 修复鸿蒙媒体代理在 CDN 拒绝、异常或播放器断连后未及时释放请求，以及发送失败未及时处理的问题。
- 修复部分长视频存在多个分段索引时遗漏后续分段，及估算字节区间越过文件末尾的问题。

## ⚠️ 破坏性改动 / Breaking Changes

- 无新增破坏性改动。系统要求和发布签名保持不变：Android 7.0 / API 24，HarmonyOS 6.1 / API 23。
- 画质仍受账号权限、片源和设备解码能力限制；用户暂停、观众控制申请与房主审批规则继续保留。

## ⚡ 性能优化 / Performance Improvements

- 断连、失败或切换播放会话时及时取消解析和上游媒体请求，减少无效下载与资源占用。
- 限制自动恢复的重试次数和等待时间，避免恢复任务长期占用播放器队列。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 更新 README、CHANGELOG、Android / HarmonyOS 维护文档及 B站恢复验证记录；依赖版本未变。
- 修复阶段已通过 246 项自动回归、类型检查、双端签名构建，以及鸿蒙模拟器三轮中断和手动 720P 暂停恢复补测。用户确认测试通过；具体模拟器和实体设备验收边界见维护记录。
- 提供签名 Android APK、HarmonyOS HAP 和构建时生成的 `SHA256SUMS.txt`；源码更新至 main，使用 GitHub 自动生成的源码归档。
- iOS / iPadOS 保持 2.1.10 / build 31，本轮未改动或构建；NAS 和服务端部署未变。
