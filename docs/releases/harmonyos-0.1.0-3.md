## 修改

- 分享端收到有权限成员发起的非空 `current-movie` 事件后，会加载并广播新影片；仅保留恢复过程中对意外空值的保护。
- 片单切换等待服务端 ACK，失败时显示原因，避免本地先行高亮造成误判。
- 观众收到 ACK 后若 12 秒仍只收到旧片源，会提示刷新分享端。
- 增加双端回归：观众点击第二部影片后，验证分享端视频元素实际从第一部切到第二部。
