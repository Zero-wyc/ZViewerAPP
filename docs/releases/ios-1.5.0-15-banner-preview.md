# b15 音乐首页横幅与手动滑动补充

2026-10-02，仍为 iOS 1.5.0 / b15 源码预览。未提交 EAS Build/Update，未生成新 IPA。

用户反馈横幅两侧留白，并要求支持手动左右滑动。原因是横幅复用了专辑封面的 CDN 方图参数，再以 contain 居中展示。现在横幅移除网易云 CDN 的 param 方图裁切参数，保留其他查询参数；原图以 cover 等比铺满 2.4:1 的整个区域，不拉伸。其他域名的签名参数不改，专辑封面继续使用 300y300。MediaImage 同时保留调用者已有的 source 属性（包括代理请求 headers）。

横幅左右滑动切换，首尾循环，定位条点击仍可切换；横向位移超过自适应阈值才切换，短距离和主要竖向手势不会切换，多指不触发切换。手势判断采用本次触摸起点与终点坐标，避免连续手势中的累计位移误判。滑动过程中暂停自动轮播，手动切换后至少间隔六秒才允许自动推进；减少动态效果设置保持关闭自动轮播，手动入口继续可用。提供辅助功能上一张/下一张动作。

验证：70 项单测、lint/typecheck、本地 iOS Hermes/Web 导出通过；扩展 check-followup-ui.cjs 的 60 项检查全部通过，0 JS 异常。四尺寸检查真实 Image 区域与横幅框完全重合，并模拟网易云域名确认请求没有方图 param、保留 quality。CDP 触摸覆盖左右切换、双向首尾循环、短拖动、主要竖向拖动、切换后的保持、定位条，以及在横幅上竖向滑动实际滚动音乐页面。既有歌单、漫游、弹幕和横竖布局检查一起复验。

证据：[脱敏结果](ios-1.5.0-15-banner-evidence.json)。截图为 RN Web 中生成的宽幅诊断图片，不是真实网易云推广内容：[平板竖屏](ios-1.5.0-15-banner-ui/home-hero-820x1180.png)、[手机竖屏](ios-1.5.0-15-banner-ui/home-hero-390x844.png)。本机 Expo Go manifest 与更新后 iOS dev bundle HTTP 200，包含新版原图横幅与手势代码。现有 Expo Go 项目 Reload 即可预览，真机触摸手感与真实 CDN 加载仍请设备复验。I13 与原生媒体验收限制沿用前次记录。

脚本仍使用隔离 7343/7347 服务；IOS_TEST_OUTPUT 指定新证据目录避免覆盖历史。IOS_BANNER_ONLY=1 可只运行首页/滑动/日推的 21 项检查，完整运行包含 60 项。没有新增应用依赖。
