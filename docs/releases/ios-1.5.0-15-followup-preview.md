# b15 歌单、漫游、弹幕与横竖布局预览补充

2026-10-02。当前仍为 iOS 1.5.0 / b15 源码预览；未提交 EAS Build/Update，未生成新 IPA。用户明确要求先用 Expo Go 检查界面。此次对照指定仓库中 client-v1.5.0 的 MusicHomePage、MusicDailyPage、MusicFmPage 和 DanmakuSearchModal，保持 RN + VLC 架构。

- 网易云歌单增加“全部播放”和“全部加入播放列表”。以 100 首分页加载整份歌单，先核对完整内容，再执行替换；替换后从首曲播放，追加保持当前曲目和播放状态。逐首等待 v4.2.1 ACK，保留顺序及重复歌曲，显示进度与取消入口。服务端没有原子替换接口：写入中失败/取消可能留下部分队列，会报告已完成数量；重试不保证自动去重。分页失败在清空之前发生，旧队列保留。
- 私人漫游使用专用三封面、四角框、MODE、喜欢/不喜欢/上一首/下一首界面。默认、熟悉、探索、场景、AI DJ 及运动/专注/夜晚场景沿用双端端点；模式空结果回退默认源。候选低水位补充，当前漫游曲目自动结束和手动切歌均继续取推荐，没有固定批次结束限制。候选池 32、返回历史 200 的内存上限不限制向前漫游。重复服务端批次允许再次推荐历史曲，避开立即重复当前曲。账号/房间/模式改变取消旧请求；观众不直接操控漫游队列。动画和房管完整权限尚未等效迁移。
- 在线搜索弹幕改为有固定关闭入口的弹窗，来源下拉最多 200 高度，结果/集数各自滚动，平板双栏、手机分步返回。结果保留封面、简介和基础统计；B站封面使用既有代理。集数只显示名称，每行两个，点击仍获取并保存轨道；playbackParams 原样回传。导入失败保留选择供重试，不发布空轨道。
- 竖屏视频区域使用实际 body 高度计算明确像素高度，下方菜单独立收起/展开。横屏根据实际 body 宽度计算媒体和右侧菜单宽度，不依赖内容决定 flex 分配。展开状态跨方向保留，横屏自动放在右侧。Expo Go 隐藏方向控制；安装版检查方向能力后提供手动旋转并锁定、锁定当前方向、恢复自动旋转。全屏仍独立保存/恢复方向策略。此前桌面检查没有覆盖用户报告的原生布局故障，不能作为原生通过证明。
- 音乐首页改为完整比例横幅、轮播定位条和上下分离的每日推荐卡。推荐卡有双角装饰、日期、播放入口，遵循浅/深主题和减少动态效果。日期随本地午夜/回到前台刷新。每日推荐默认当天（用户指定），日期下拉只列服务端返回的历史日期；历史权限/接口失败保留今天的内容和说明。历史走 /history/recommend/songs/detail?date=，当天走 /recommend/songs，两个批量按钮也用于日推。

验证：69 项单测、lint/typecheck、iOS/Web JS 导出通过；新增 Web 46 项、原房间 59 项、展开音乐 31 项通过，均 0 JS 异常；Yoga 24 种布局检查通过。新增检查覆盖 130 首分页、加载失败保留旧队列、真实追加/替换/首曲状态、跨推荐批次切歌、模式/场景参数、80 个搜索结果和80集滚动、集标签双列、实际轨道保存、反复横竖切换、首页四尺寸和历史日期切换。单测连续推进 220 次，确认没有有限批次终止。服务端是隔离官方 v4.2.1；NCM歌曲/图片/弹幕搜索内容为 fixture，不代表真实账号、推荐服务或音视频成功验收。
