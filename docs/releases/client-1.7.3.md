## 🚀 新特性 / Features

- Android / HarmonyOS 升级至 1.7.3（173），对齐 ZViewer 服务端 v4.4.7。
- 添加影片支持 B 站关键词搜索，选中结果立即解析，继续选择分 P、画质和添加。
- 完整片单集中搜索、触屏上移/下移排序与房主自动连播；连播默认关闭，片单末尾停止。
- 弹幕添加成功后保持窗口打开，按来源和集数标记已添加，可继续添加其他集数。
- Emby/Jellyfin 新增海报墙、年份、目录导航、缺图占位及当前目录全选/取消全选，支持整季批量添加。

## 🐛 错误修复 / Bug Fixes

- 修复单集海报墙隐藏封面的问题，恢复 16:9 单集图片；剧集和季保留 2:3 海报。
- 修复媒体库放大后目录仍固定高度的问题，目录区填充剩余可用空间，手机窄屏无横向溢出。
- 修复原生页面图片地址、长标题与面包屑布局，保留所选服务器连接映射与图片失败占位。
- 修复播放器重挂载清掉自动连播开关、B 站搜索选中后解析旧输入，以及搜索旧响应/分页重复问题。
- 补齐弹幕来源隔离、失败重试及换房轨道清理；二级面板返回先退出面板全屏，再关闭顶层。
- 保留 1.7.1 的 Kazumi HLS 代理、鉴权和切片进度修复。

## ⚠️ 破坏性改动 / Breaking Changes

- 无客户端破坏性改动。本轮新功能以服务端 v4.4.7 为对齐目标；海报字段或图片接口缺失时仍可列表浏览和添加。
- 排序遵守服务端权限，仅 root 或创建房间的管理员可操作；Kazumi 仍需手动启用。
- 本次仅发布 Android / HarmonyOS，不更新 iOS。新增评论独立窗口、评论侧坞与修饰键快捷唤出未移植。

## ⚡ 性能优化 / Performance Improvements

- 海报按需加载；失效的搜索/目录响应不覆盖当前内容，分页去重和并发保护减少重复操作。
- 媒体库目录使用可用视口与内部滚动，放大后提高显示空间利用率；单集使用横向封面便于连续选集。
