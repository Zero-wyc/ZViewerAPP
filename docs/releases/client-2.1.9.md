# ZViewer-Client V2.1.9

Android / HarmonyOS 同步更新为 **2.1.9 / 219**，对齐服务端 v4.7.4，完善播放设置即时应用、源解析同步、B站解码防护与语音媒体监看。详细验收层级见 [2.1.9 验证记录](https://github.com/Zero-wyc/ZViewerAPP/blob/main/docs/client-2.1.9-validation.md)。

## 🚀 新特性 / Features

- 非 B站影片卡增加运行时“播放设置”，可独立切换服务器中转与浏览器转码；当前影片保存后即时应用，保持播放进度、倍速与暂停意图，其他影片下次播放时使用新设置。
- 影片卡采用紧凑的图标＋粗体中文胶囊。文字与左图标垂直居中，关闭时文字在图标右侧区域居中；开启后文字左移、显示主题色高亮及勾号，图标和按钮尺寸不变。
- 添加影片继续使用原有说明卡＋滑动开关，草稿与运行设置相互独立。胶囊适配窄屏、平板及字体放大，点击高度至少 44px，并尊重减少动态效果设置。

## 🐛 错误修复 / Bug Fixes

- 修复设置保存时 HTTP/Socket 乱序、迟到片单及旧会话覆盖，避免显示新设置却使用旧策略；播放应用失败保留已保存设置、同步暂停并提供重试。
- 补齐 ani-subs 明确关闭转码、Kazumi 旧记录解析与有效 URL 回退、源站请求头和相对代理处理；观众中转策略支持双向同步，避免固定到添加者服务器或重复套代理。
- 修正 Android Go / HarmonyOS ArkTS B站真实请求的 fnval 位，接收 HDR 元数据并按准确编码能力防护；不支持的手选档位保留原播放，保留账号和 CLI-only 边界。
- 语音依据实际媒体 PC/ICE 判断连接，补充加入、重连和中断约 10 秒反馈；等待麦克风授权单独处理，清理旧会话监看与监听。

## ⚠️ 破坏性改动 / Breaking Changes

- 无新增破坏性协议变更。Android 最低 API 24，HarmonyOS 最低 SDK 6.1.0(23)。
- 手动 HDR 和音乐背景 HDR 仍未开放；真实设备 HDR、通话与特定线路验收范围以验证记录为准。
- 本轮仅发布 Android 与 HarmonyOS；iOS 不构建、不发布。

## ⚡ 性能优化 / Performance Improvements

- 同 URL 策略变更只应用一次，重复确认及广播不重复重挂载；旧房间、旧请求与已取消加载不能继续消耗媒体任务或恢复播放。
- 胶囊切换仅移动内部文字并显隐勾号，固定按钮与图标尺寸，减少界面跳动；减少动态效果时接近即时切换。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步安卓、鸿蒙维护文档、v4.7.4 执行文档与最终 2.1.9 验证记录，保留 2.1.8 为历史本地迭代记录；依赖版本不变。
- 240 项适配、4 项媒体、Go core/mobile 与 6 项 vendor 检查通过；系统字体及华文行楷的 24 组几何验证、双端 Debug 模拟器界面及本轮播放逻辑的 HLS 双向播放/策略切换验证通过。正式签名 Release 的签名、资源与版本检查通过，实际测试包版本和真机范围独立登记。
- 发行资产为正式签名 APK、HAP 与构建时一次生成的 `SHA256SUMS.txt`。源码同步 main / `client-v2.1.9`，使用 GitHub 自动源码归档，不另打源码压缩包。
