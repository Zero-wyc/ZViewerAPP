# ZViewer-Client V2.1.7

Android / HarmonyOS 同步更新为 **2.1.7 / 217**，修复 B站短链、竖屏高清播放及服务端账号解析问题。用户已反馈测试通过，详细范围见 [验证记录](https://github.com/Zero-wyc/ZViewerAPP/blob/main/docs/client-2.1.7-validation.md)。

## 🚀 新特性 / Features

- 一起看全屏按视频实际方向锁定：竖屏视频默认竖屏，横屏视频延续原有横屏播放；在全屏内换视频时自动复核方向。
- 添加面板分别标注“服务端 B站账号”和“本机 B站账号”，显示当前解析来源，避免两处登录状态混淆。

## 🐛 错误修复 / Bug Fixes

- 补齐 B站分享文本与短链的后续操作：切画质和分 P 复用展开后的完整地址，保留 `?p=N` 参数，显式分 P/CID 优先。
- 修复竖屏 720×1280、1080×1920 轨道被横屏高度上限误排除，导致 480P 以上提示无可用解码器的问题；仍核对编码、帧率、设备能力与账号权限。
- 修复普通 B站视频仅登录服务端账号、未登录本机代理时无法解析和添加的问题，覆盖预览、切画质、分 P 与播放。
- 恢复服务端 DASH 的房主画质选择；本机解析权限错误仍明确提示，CLI-only 内容继续要求已登录的本机代理。
- 保留全屏退出、离房时的方向恢复，以及手动解除旋转锁定的行为。

## ⚠️ 破坏性改动 / Breaking Changes

- 无。房间协议与既有影片兼容，CLI-only 的本机账号要求保持有效。
- Android 最低 API 24，鸿蒙最低 SDK 6.1.0(23)。本轮发布平台为安卓与鸿蒙。

## ⚡ 性能优化 / Performance Improvements

- 展开后的规范地址用于后续画质与分 P 操作，减少重复短链跳转。
- 方向控制复用当前视频元数据，相同比例的尺寸事件不反复下发方向锁定。

## 📖 文档与依赖更新 / Documentation & Dependencies

- 同步安卓、鸿蒙维护文档、账号路由专项记录和版本验证记录，依赖版本不变。
- 215 项适配、4 项媒体、Go core/mobile 回归通过；双端模拟器验证竖屏实际 DASH 解码及全屏方向，隔离服务端接口验证仅登录服务端账号时的完整添加与播放流程。
- 原生模拟器、接口夹具和安装包检查的范围分别记录，用户“测试通过”作为本次验收反馈；不扩大为全部设备或私有 NAS 配置的覆盖。
- 发布已验收的正式签名 APK、HAP 与构建时生成的 `SHA256SUMS.txt`。源码同步 main，使用 GitHub 自动生成的源码归档。
- iOS 维持既有公开版本，本轮不构建或发布 IPA。
