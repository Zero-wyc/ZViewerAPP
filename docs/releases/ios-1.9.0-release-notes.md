# ZViewer iOS 1.9.0

独立 iOS 发行，应用版本 **1.9.0 / build 26**，支持 iOS / iPadOS 16.4 及以上的 iPhone / iPad。

## 更新内容

- 播放栏、字幕 / 弹幕设置对齐 Android / HarmonyOS，横屏设置从右侧展开，移除音轨设置。
- 补齐固定、滚动、彩色、高级弹幕的显示 / 屏蔽，保存本机偏好；移除手动 XML / JSON 文件导入及 JSON 内容编辑，保留在线搜索和轨道偏移。
- 投屏新增全屏、刷新、暂停 / 继续接收和内嵌聊天，刷新保持全屏状态。
- 屏幕方向改为一键切换：切换并锁定横竖屏，锁定后点击恢复自动旋转；全屏方向按钮采用相同逻辑，退出全屏恢复自动旋转。
- 房间语音调整为状态、全局 / 麦克风音量、成员音量条与底部操作布局。
- 房间设置集中展示模式、房间状态、名称 / ID、分享、在线成员与审批；保留独立的入房审批与播放申请自动通过开关。
- 网易云导航与头像菜单互斥，使用不透明背景；横屏菜单限高滚动，“音乐设置”统一从头像菜单进入。

## 安装与校验

下载 `ZViewer-iOS-1.9.0-release.ipa`，使用自己的证书和设备授权工具签名后侧载。**IPA 未签名，不是 App Store / TestFlight 安装包。** 包内包含生产 Release JS，启动无需 Metro 或 Expo Go。摘要见附件 `SHA256SUMS.txt`；源码使用本标签的 GitHub Source code 归档。

## 验证范围

227 项测试、lint、TypeScript、设备 Release 构建与离线 IPA 核验通过。界面、方向切换、菜单互斥已在 iOS 模拟器检查；阶段性页面检查覆盖手机 / 平板横竖屏及深浅色。

真实跨端 WebRTC / OBS、语音听感 / 蓝牙、硬件解码、锁屏系统按钮与后台自然跨曲仍需真机专项验证；JS 被系统挂起时没有独立原生房间 Socket / 自动切歌管线，保留此前限制。

构建和包检查：[iOS 1.9.0 / 26 验证记录](https://github.com/Zero-wyc/ZViewerAPP/blob/ios-v1.9.0/docs/releases/ios-1.9.0-26-validation.md)。
