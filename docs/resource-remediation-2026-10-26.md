# Android/HarmonyOS 资源合同修复（2.2.6 / 227）

本轮依据 `client-server-review-remediation-2026-10-26.md`，配合服务端 S01～S15 修复；原方案保留为审查时的记录。iOS 未修改、未构建。

- C01：服务端自有 Emby/Jellyfin 封面使用可移植资源身份与一小时图片能力；图片 tag 是不透明能力，前端保留原值。系统媒体通过当前服务器与原生通道解析相对封面，兼容路径前缀及重连；房间内每四十分钟及回到前台时续签封面，仅更新 cover，保留其他播放字段，切服/退房/旧响应不复活会话。
- C02：两处网易云账号头像、歌单选择和歌曲搜索的图片统一调用现有 `neteaseImageUrl`，替换尺寸查询并保留其他参数，沿用错误回退。
- 推流观众通过认证 `/api/stream-push/watch/{roomId}` 领取独立观看票据，映射到当前服务器/原生连接。待审批不建立媒体；请求失败不回退到发布码，取消后迟到响应不恢复播放器。退出继续使用现有组件卸载和房间清理流程。
- 本地影片按 movieId 播放，服务器使用权威路径校验房间准入。原始 path 构造只用于 root 尚未发布的预览；观众播放不再依赖这个管理能力。
- 字幕先校验 HTTP/业务状态、格式和 2 MiB 大小再调用选轨处理；413 / SUBTITLE_TOO_LARGE 显示明确提示，权限拒绝或超限保留原字幕，不解析/广播失败内容。
- 显式 sourceMountId 继续发送；服务器负责归属、同址账号选择、改密与删除后的正确拒绝，客户端不降级为仅传 serverUrl 或无授权通用代理。
