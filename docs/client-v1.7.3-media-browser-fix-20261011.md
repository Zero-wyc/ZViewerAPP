# Android / HarmonyOS 1.7.3 媒体库界面修复（2026-10-11）

根据用户 1.7.2 真机截图修复三处遗漏。版本统一为 **1.7.3 / 173**，共享入口 `src/upstream/modules/emby/EmbyBrowser.tsx`，Jellyfin 复用同一实现。原 1.7.2 布局检查仅验证等高、无溢出和按钮可达，没有验证单集封面和放大后目录高度，结论不能涵盖这两项。

## 修复行为

- 单集海报墙恢复实际图片代理：原 Episode 分支直接显示 Film 图标，即使有 imageTag 也不创建图片。现在正常加载封面，单集采用 16:9 图片；剧集和季仍为 2:3 海报。缺少元数据或过期图片继续使用相同比例占位，标题两行、卡片等高。
- 放大后真正显示更多内容：原目录区固定 `min(420px,50dvh)`，仅外层面板变大。现在媒体库面板、内容容器和目录区使用连续 flex 布局，普通高度 `min(720px,85dvh)`，放大填满可用安全视口；目录区占用标题、工具栏、底部操作以外的空间并内部滚动，消除截图中的大片空白。
- 添加“全选 (数量) / 取消全选”：选择当前目录全部 file，排除目录和上级路径，自动进入多选；可取消单项后再次补全。按目录原始顺序交给既有批量添加流程，列表/海报切换保留选择，进入其他目录清空，加载中禁用选择和添加。
