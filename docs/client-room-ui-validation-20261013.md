# Android / HarmonyOS 房间界面优化验证

日期：2026-10-13。基于现有 **1.8.0 / 180** 的本地候选；本轮未提升版本号或发布 GitHub Release。

## 界面行为

- 一起看视频下方只有聊天、片单；房间标签删除。
- 右上角房间按钮统一承载一起看/一起听切换及房间管理、分享、在线观众和离房入口。房主可切换，观众无切换按钮；观众通过服务端广播跟随模式变更。
- 一起听头像菜单保留音乐账户、设置、Cookie 登录与登录/退出功能，移除房间模式选择。
- 一起听右侧侧栏仅显示评论列表、输入与发送，移除房间状态、流量统计和重复语音内容；语音继续从顶部耳机按钮进入。
- 触摸点击把手可展开/收起；触摸不触发鼠标悬停逻辑，把手不会被侧栏遮住。
- 房间面板关闭时仍挂载房间事件监听；隐藏后不占布局、不锁滚动、不消费返回事件。嵌套设置先响应返回。
