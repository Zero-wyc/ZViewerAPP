# 服务端对齐：2.3.5 / 235（2026-10-31）

## 基线

服务端指定目录从 GitHub 同步至 main `e1ed57c31662e5920130af0ca93d89f5cd419720`，本地分支 `sync/upstream-20261031`，受管源码与上游一致，未另建旧版本备份。OBS 后台在线与停流宽限 PR #40 已合入本次基线。本地更新不代表 NAS 或其他现有部署已经更新。

客户端在指定 `ZViewer-client` 仓库 main 上从 2.3.4 / 234 更新到 2.3.5 / 235。只同步 Android / HarmonyOS 共享业务增量；保留本机 B站解析、原生音频/后台、触屏布局、手势和 2.3.4 播放恢复，不启动 iOS 构建。

## 改动

| 服务端增量 | 客户端处理 |
| --- | --- |
| LiveKit 按需下载 | `useVoiceComponent` 查询状态和进度；面板提供安装、进度、失败及重试，明确组件安装在服务器。状态查询兼容旧服务端 404，外置 LiveKit 直接保留加入入口 |
| 公开入口开关 | `systemSettingsStore` 接收两项开关，缺省为 true、显式 false 生效。移动房间隐藏语音入口；工具坞隐藏语音/流量。隐藏面板保留既有语音会话 |
| 登录续期通知 | 优先识别 TOKEN_EXPIRED；旧服务端仅本地 JWT 已过期时兜底。临时失败最多三次，权限撤销、踢出、关房、登出、换服和身份变化不能复活旧连接 |
| OBS 停流宽限与状态广播 | 已有 `useStreamStatus` 继续消费状态；FLV 错误与 EOF 持续恢复，快速退避后每 10 秒重试。首次无媒体不受点播 30 秒超时影响，卸载/取消立即释放 |
| 指定分P链接 | 正确识别 p/page，已有选择不重复弹窗；切画质保留 page/CID，外部 CLI 缺 CID 时补齐，PGC 不走 UGC 查询 |
| 一起听分P推荐命名 | 导入、推荐入队、自动续播和观众申请共用分P名称、合集与实际时长；合并详情查询。切房、换曲、暂停、seek、断线或控制意图变化丢弃迟到结果 |

手机不新增桌面 FRP、CDN 组件下载或服务端管理页面。语音组件实际下载与解压仍由服务端执行，客户端状态查询和失败/重试分别验证。

## 发布与边界

目标包为 `release/client-v2.3.5/ZViewer-Client-2.3.5-android.apk` 与 `ZViewer-Client-2.3.5-harmonyos.hap`。沿用正式签名，网页资源来自同一次生产构建；最终每个安装包只计算一次 SHA256，发布复用记录。源码发布至 main，标签 `client-v2.3.5`，使用 GitHub 自动源码归档。

最终 APK 为 76,781,625 字节，HAP 为 14,401,772 字节。构建日志、签名/资源检查、一次 SHA256 与发布记录位于忽略目录 `release/client-v2.3.5/`；浏览器交互证据位于仓库外 `tools/server-alignment-20261031/browser/checks.json`。

本轮 ADB / HDC 没有在线设备。自动回归、浏览器受控组件、本地真实服务和签名包检查分别记录；没有新增 Android/HarmonyOS 实体设备听音、跨设备播放、浏览器真实后台 40 分钟或 NAS 部署验收。iOS 版本与工程未变。
