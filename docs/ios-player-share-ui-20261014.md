# iOS 播放、语音与投屏界面对齐（2026-10-14）

本轮按用户提供的 Android / HarmonyOS 截图调整 iOS。只更新源码与验证记录，版本仍为 1.8.6 / build 25；没有生成、签名或发布新的 IPA。

## 界面与操作

- 一起看采用深色圆角播放栏：进度条置顶，播放时间、弹幕输入、倍速、音量、刷新、设置及全屏归入同一区域；短宽度时分两行，全屏提供方向切换，横屏全屏提供隐藏控件。输入弹幕、调整进度、切换方向或打开弹窗期间暂停自动隐藏，拖动进度不被持续更新的播放时钟打断。
- 播放设置只保留“字幕 / 弹幕”两页。横屏从右侧展开，竖屏居中；移除音轨选择界面，保留播放器内部的音频解码配置。倍速与本机音量从播放栏直接进入。
- 字幕首页为启用开关和高级设置，内嵌轨道、外部地址、文件导入、同步和偏移保留在高级设置内。启用开关可以恢复先前的字幕选择，媒体重新加载后不会恢复旧片源的原生轨道。
- 弹幕首页直接显示区域和不透明度，更多设置中保留字号、穿屏时间及随屏缩放；弹幕轨道管理可独立展开。
- 房间语音采用状态摘要、全局音量、麦克风音量、成员音量条和底部操作布局。音量接入 LiveKit 远端播放与本机 WebRTC 音频源；耳机按钮为暂停 / 恢复收听，麦克风状态独立。默认静音加入、后台释放与管理员禁言逻辑继续生效。
- 投屏采用黑色画面、深色浮动控制栏和连接状态标签。新增全屏 / 退出全屏、刷新、暂停 / 继续接收及全屏方向切换；普通模式直接展示聊天区。WebRTC 刷新关闭旧 peer 并重新发送一次 viewer-ready，OBS 刷新替换本机 VLC 拉流；刷新保持当前全屏状态。OBS 保留拉流地址设置并提供播放器已有的画中画入口。

## 屏幕方向补充

核对 `src/mobile/PlayerDisplayControls.tsx`、`src/platform/playerDisplay.ts`、Android `PlayerDisplayPlugin.java` 与 HarmonyOS `Index.ets` 后，iOS 顶部、一起看全屏与投屏全屏统一复用 `ScreenOrientationButton`。直接复用 Lucide 的 Smartphone / RectangleHorizontal / LockKeyholeOpen 路径，并附上原许可证。

- 自动旋转时，当前竖屏显示横屏图标，点击切换并锁定横屏；当前横屏显示竖屏图标，点击切换并锁定竖屏。
- 已锁定时显示解锁图标，点击恢复自动旋转。移除“屏幕方向”选择弹窗与误做的播放控件锁；方向切换不会禁用或收起播放按钮。
- 进入全屏锁定横屏，退出全屏、切换模式或离开房间恢复自动旋转。退出全屏不恢复进入前的手动方向锁，与另外两端保持一致。
- 原生方向请求串行处理，连续进入 / 退出全屏、模式切换或卸载时，以最后操作为准，避免旧锁定迟到覆盖退出。

当前 `npm run check` 全部通过，测试共 **219 项**，新增 8 项方向动作、全屏状态、失败重试、并发退出与生命周期回归；iOS / Web 导出通过。更新旧控件锁断言后重跑播放 / 投屏页面检查，**49 项通过、0 个运行时错误**，报告与原生投屏截图位于 `ZV-iOS/.expo/orientation-evidence/`；浏览器不支持原生方向切换，方向行为由单测和原生模拟器验证。iPhone 18 Pro / iOS 27.0 模拟器已验证顶部一键横竖屏、自动旋转、三种图标、一起看全屏方向切换与退出恢复、投屏全屏解除方向锁后操作栏仍可用，刷新保留全屏和方向状态。该检查使用现有 Debug 二进制与当前 Metro 源码、本机隔离空房间，不涉及真实媒体播放或新安装包验收。
