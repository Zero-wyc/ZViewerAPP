# 安卓全局背景适配

完成日期：2026-10-01。

## 行为

- 安卓端的连接页、房间列表、观影房间、音乐房间共用一个背景引擎。切换页面或房间模式时，背景层保持挂载。
- 背景图片、模糊、遮罩、位置、缩放、旋转沿用原来的主题存储；不重置用户偏好。
- 房间的标题栏、聊天/片单/房间面板和语音面板使用统一的文字、圆角与玻璃参数。
- 文档根节点同步主题变量，让渲染到 `body` 的房间弹窗、播放器设置和消息提示也能读取外观设置。
- 房间内通过顶部“房间设置 → 外观设置”调整主题。首页保留原有悬浮入口；房间内不显示悬浮按钮。
- 视频画布保留黑色底板及适合播放控件的文字色。切换主题不会重建视频元素。
- 全局接入由 `isGlobalAppearanceRuntime()` 控制，在 Android 与 HarmonyOS 同时启用；iOS 独立工程不在此次同步范围。
- 1.3.0 两端共用浅色设置深色文字、主题强调色账号入口；内部 main/side 禁用重复玻璃模糊，弹幕分组透明。对照验收与正式包校验见 [1.3.0 发布记录](releases/client-1.3.0.md)。

## 修改位置

- `src/App.tsx`：将安卓房间与首页放在同一个 `MobileAppearance` 中。
- `src/mobile/MobileAppearance.tsx`：同步根节点变量、接收房间外观入口事件，并按场景显示入口。
- `src/mobile/MobileRoom.tsx`：房间设置增加外观入口。
- `src/mobile/appearance.css`：房间玻璃效果、共享主题变量及弹层样式。
