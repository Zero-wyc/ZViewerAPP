# 双端播放器界面、歌词与手势验收

日期：2026-10-02。基于已发布 1.3.5 及后续系统媒体维护提交 `636e701`，本轮保持版本 1.3.5 / 135，生成本地调试 APK、签名调试 HAP 和对应提交源码 ZIP，不覆盖现有 GitHub 发布标签。后台播放用户已确认通过。

## 修复原因与行为

一起听展开横屏后，房间外层仍保留摄像头、底部系统导航的安全区 padding，导致覆盖层背景从安全区内开始绘制。现将安全区移到前景内容及收起按钮，网易云渐变和哔哩哔哩视频覆盖整个视口，曲绘继续避让摄像头。原生工具栏中重复的浏览器全屏入口已隐藏，网页端继续保留。

网易云头像可能返回 HTTP CDN 地址或已有 `param` 查询参数。原生安全来源会阻止混合内容，直接拼接尺寸参数也会生成错误 URL。现统一解析 URL、升级网易云 CDN HTTPS、保留其他参数并替换尺寸；主评论、楼层回复和个人头像使用同一规则，加载失败显示内置头像。

此前歌词只供界面面板使用，原生媒体快照未携带歌词。现让界面和系统共享歌词请求，原生端独立加载完整 LRC 并计算当前行，切歌清空旧歌词。鸿蒙写入标准 AVMetadata 歌词字段；安卓写入完整 LRC 兼容性元数据和通知当前行。安卓标准媒体界面没有鸿蒙式独立歌词页，系统或控制器可能选择不展示相关字段。

一起看原来依赖 ArtPlayer 的单击暂停与双击全屏行为。双端现用中间区域双击播放/暂停，全屏左右区域双击跳转 15 秒，单击只显示控件。保留显式控件与房主/观众权限规则。

## 环境与方法

- Android SDK 手机模拟器 Medium Phone，原生调试应用；鸿蒙 Pura 90 Pro 模拟器，原生签名调试应用。
- 使用隔离的 source-code 服务端及数据库、七分钟本地音视频和确定性音乐 API 数据。评论头像使用实际网易云 HTTPS CDN 图片，同时模拟无效图片与已有查询参数。
- 通过 adb / hdc 安装与控制模拟器，使用 WebView / ArkWeb CDP 操作真实打包界面和媒体元素；系统歌词通过鸿蒙 AVSessionService `hidumper`、安卓 `dumpsys notification` 检查。未使用 computeruse。
- 横屏检查视口约为安卓 914×411、鸿蒙 789×359 CSS 像素；分别注入左侧/右侧 42px 与底部 20px 安全区，平台提供的实际安全区同时保留。

共享 TypeScript 检查、Vite 构建、两端资源同步、Android `assembleDebug` 和 HarmonyOS debug `assembleHap` 均通过；源码差异空白检查通过。生成资源、测试数据库、账号会话、截图、日志和签名材料不纳入源码提交。测试结束恢复原连接与偏好，退出测试房间，停止测试服务与模拟器。

## 验证边界

本轮验证真实原生宿主与共享播放器，但音乐 API 内容使用隔离数据，没有重新执行联网账号扫码及整条在线音视频解析链路。网易云头像实际网络下载与解码已检查。鸿蒙原生转储确认完整 LRC，独立歌词页的具体样式仍由系统决定；安卓通知确认当前行，不能推断所有厂商的快捷播放面板都会显示歌词。逐行自定义偏移和翻译显示偏好未同步到系统歌词。

自动旋转和后台媒体生命周期沿用 [2026-10-01 验收](mobile-media-lifecycle-2026-10-01.md) 的已通过实现；本轮覆盖横竖屏界面切换，未重复五分钟后台专项。用户本轮报告后台播放通过，长时间待机和不同厂商省电行为不由这次 UI 回归推断。
