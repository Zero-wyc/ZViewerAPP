## 实现

- B 站关键词搜索：复用搜索接口，关键词响应代际隔离，分页去重与并发保护，清理高亮标签，图片沿用服务器代理和连接映射。选中 BV 地址后直接把该地址传给解析函数，保留原来的本机解析、PGC、画质、分 P、权限和凭据边界。
- 完整片单集中搜索；上移/下移适用于触屏。过滤或屏幕共享时禁用排序。真实 REST 权限为 root 或创建房间的 admin，admin 通过既有只读房间元数据确认 owner；不把当前分享端或 manageMovie 授权视为排序权限。提交后等待服务端广播，不乐观修改列表；失败提示并尝试读取权威片单。
- 房主自动连播：默认关闭、不持久化、不广播开关。ended 读取最新完整片单，走现有 play-movie 确认和 register-host 修复重试；重复 ended、预览、屏幕共享、取消开关、删片、房主转移和离房均有守卫，末尾停止、不循环。播放器重挂载保留开关，实际角色变化才清理；新增针对回归测试。
- 弹幕连续添加：成功后保持窗口打开，按 source:episode.id 标记和去重；跟随实际轨道状态，失败回滚后可重试，删除后可重加，换房清空旧轨道；异步搜索/集数响应失效控制。搜索和集数分别滚动，窄屏按上下布局，不撑宽页面。
- Emby/Jellyfin：两种目录类型均补 imageTag/productionYear，Jellyfin 独立图片 API；按用户选中的服务器及原生连接通道构造图片地址，不添加账号 token 或媒体库 API Key。缺图、过期图或旧服务器字段缺失使用占位，仍可列表浏览和添加。列表/海报墙切换，手机海报等宽等高，长标题最多两行，面包屑截断；Episode 目录为紧凑选集网格，支持勾选多集及整批添加。
- 二级面板：统一开关动画、可用视口扩展、VisualViewport 键盘可用高度、原生安全区与内部滚动；原生返回和 Escape 优先退出面板全屏，再关闭最上层面板；继续保留播放器和设置返回链。Kazumi/AniSubs 集数采用 grid 行高动画；保留既有移动设置滚动布局，CLI-only 图标统一为锁。
- 评论独立弹窗、右缘滑出评论、双击修饰键及相关设置均未移植；现有评论、实时弹幕、一起听和语音保留。未变更 Go/ArkTS 解析协议。

## 验收边界

本轮使用隔离本地服务端与短时 H.264/AAC 视频、HLS 和媒体库协议夹具；海报的实际浏览/代理链与 App 渲染可以验证，但不等同于用户真实 Emby/Jellyfin 服务器的刮削与播放兼容验收。HTTP 与正常/异常 HTTPS 的地址映射有单测；原生设备实际自签名通道、第三方 B 站/Kazumi 正片、真实音轨听音、蓝牙/后台/系统控件、10 分钟关房/重开、物理设备和 iOS 不在已通过结论内。

签名安装包发布及真实服务器/设备验收遵守原清单；不能将本轮 fixture、API 200 或片单高亮当作真机完整验收。
