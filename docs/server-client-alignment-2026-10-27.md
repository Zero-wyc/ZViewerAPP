## 一起看手势：2.2.8 / 229

- 删除控制栏及“更多”菜单的隐藏/显示控制栏按钮，移除隐藏模式和冷却逻辑。
- 单击视频切换控制栏显隐，延迟 320ms 区分双击；显示后约 3 秒自动隐藏。控制栏按钮、弹幕输入与设置面板保留各自操作。
- 左 / 中 / 右三分区：左侧双击后退 15 秒，右侧前进 15 秒，中部播放/暂停。普通窗口与全屏均适用；双击不额外触发单击显隐，也不触发 ArtPlayer 双击全屏。
- 按住横向拖动显示目标时间，松手只提交一次跳转。以按下时的播放位置为基准，一屏宽最多调节 180 秒，短视频按实际时长缩放，结果限制在 0 至时长。
- 从视频右半边开始纵向滑动调节本机播放器音量，范围 0–100%；向上开声，降至 0 时静音。此操作不修改房间共享音量或系统硬件音量。
- 房主 / 房主离线的既有控制权限继续直接操作媒体；普通观众走原有播放、暂停和跳转申请，不擅自修改本地房间播放。
- 换片/换源、权限改变、取消触摸、多指、窗口失焦、后台隐藏及卸载会取消未完成的手势与待定单击。暂停/继续维护原有 pause-intent 标记，防止异步引擎补播覆盖用户暂停。
- ArtPlayer 自带 gesture 默认为 true，已明确关闭，fastForward 也关闭，避免原生 touch 处理重复跳转或绕过观众权限。新的 touch-action:none 只挂在 video / 大播放按钮表面，不挂整个 stage，保留设置与菜单滚动。
- 新的 watchVideoGestures 独立于一起听的 videoGestures，本轮只调整一起看。
