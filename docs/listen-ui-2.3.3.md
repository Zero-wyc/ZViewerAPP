# 一起听 2.3.3 界面改版与验证

日期：2026-10-28 至 2026-10-29。共享代码位于 `src/upstream/modules/music/`，应用于 Android 与 HarmonyOS。

## 截图复核后的布局修订

最终布局以本节为准：歌曲标题独占第一行，溢出自动滚动；歌手与红心、歌词、评论位于第二行，操作只显示图标。右上角是唯一更多入口，原底部工具栏移除；菜单按布局去重，以 280ms 滑入、200ms 滑出配合遮罩渐变，减少动态效果时直接显示。空歌曲时也能从顶栏打开设置。

横屏低于 520 CSS px 时仍保留封面：展开歌词时，标题旁显示缩略图；收起歌词时，左列显示大封面，歌曲信息、进度与完整五键置于右列。信息、进度和五键采用固定间距整体垂直居中，左右歌曲与歌词面板等高对齐。顶栏压缩到 52px，内容自 56px 起并适配左右挖孔与底部手势条。横屏纯净视频独立于更多按钮左侧，使用 MonitorPlay 图标，缺少可用视频时置灰。

横竖屏罗马音/翻译图标与音质统一放在歌词框右下角独立页脚，继承面板深浅色，不遮挡滚动歌词。竖屏取消原顶部独立按钮行，歌词面板向上扩展填满原按钮行的空间；歌词和评论模式保留两行歌曲信息与全部主控制。歌词滚动层顶部与底部渐隐，避免边缘和页脚硬切。

新增歌词顶部留白和内容尺寸观察：横竖屏切换、页脚高度变化或字体重排后，留白过渡结束继续校正当前行位置，避免沿用旧偏移使高亮行移出可视区。

各轮真实组件受控数据验证 393×852、320×568、852×393、720×320、1280×720 的布局及菜单；实际观察长标题动画、菜单进入/退出、评论/歌词切换。早期浏览器证据在仓库外 `tools/listen-ui-refinement-20261028/`，横屏补充截图在 `tools/listen-landscape-20261029/`。最终竖屏与横屏四种尺寸的元素位置、空白填充和罗马音/翻译实际点击检查记录在 `tools/portrait-lyric-footer-20261029/checks.json`；最后一轮截图采集失败，不计为截图验收。正式安装包使用 `release/client-v2.3.3-portrait-lyrics-20261029/`。以上不等于真机或多人播放同步验收。

## 验证

- 161 项维护回归、8 项工具栏回归；新增 4 项收藏行为回归和滑动后点击抑制回归。
- 真实 Vite 页面连接测试服，测试自建临时房间：单击播放、歌词控制、两个入口各仅一个、队列取消清空不丢歌、更多中的收藏弹窗、设置高级折叠；393×852 与 852×393 无水平溢出。截图位于仓库外 `tools/listen-ui-implementation-20261028/`。
- 浏览器受控组件检查：观众按钮仅申请；进度不越权本地 seek；房主审批大按钮；确认前不发送清空；排序发送完整 IDs；无管理权隐藏清空/排序。
- TypeScript/Vite 及双端 Release 签名构建；本地安装包每包只在最终构建计算一次 SHA256。

## 边界

当前服务器的在线观众事件不包含头像，也不向观众完整提供房主个人资料；使用文字头像和“房主”占位，已有姓名按服务端数据展示。没有伪造未知资料或“全部已同步”状态。浏览器与受控桥验证不替代实体 Android / ArkWeb 手势、系统音量或多人真实同步测试。

本轮授权将源码更新至 main，并按 [2.3.3 发行说明](releases/client-2.3.3.md) 发布 Android / HarmonyOS 安装包。构建和测试夹具位于忽略目录，不进入发布源码；iOS 无改动/构建。
